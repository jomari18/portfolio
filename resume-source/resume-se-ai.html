AI Project

ResuMatch — AI resume and job matcherresumatch-ph.netlify.app

Next.js · TypeScript · Gemini API · zod · Supabase PostgreSQL · Vitest · Playwright · GitHub Actions

  • Compares a resume with a job posting and returns met, partial and missing requirements, suggestions and a cover letter drafted from the resume’s facts only.
  • LLM output is constrained by a JSON schema and validated with zod; the match score is computed in code, not by the model, and every matched requirement must quote the resume word for word or it is downgraded and flagged.
  • Prompt-injection containment (inputs delimited as data, closing tags neutralised), a provider-agnostic AIProvider interface, server-only secrets, and per-IP and site-wide daily limits enforced atomically in PostgreSQL.
  • Resume text is never stored or logged; shared results are HMAC-signed and expire after 30 days; 201 automated tests in CI.
